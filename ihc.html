FRAME 01/05 · IHC

Interação Humano-Computador

O campo que estuda como pessoas e sistemas computacionais se comunicam — e que serve de base para tudo o que chamamos hoje de UX e UI.

O que é IHC

Interação Humano-Computador (IHC, ou Human-Computer Interaction, HCI) é a área que estuda o projeto, a avaliação e o uso de sistemas computacionais interativos, sempre a partir do ponto de vista de quem usa. Ela junta conhecimentos de ciência da computação, design, psicologia cognitiva e ergonomia para responder a uma pergunta simples: como fazer com que uma pessoa consiga usar um sistema para atingir um objetivo, com o mínimo de esforço e confusão possível?

Diferente do que a sigla pode sugerir, IHC não é só sobre telas bonitas. Ela cobre qualquer ponto de contato entre pessoa e máquina — um caixa eletrônico, o painel de um carro, um aplicativo de celular, um comando de voz. O que muda é a interface; o que se estuda é sempre a mesma coisa: a relação entre a capacidade humana e o comportamento do sistema.

Por que IHC importa

Um sistema tecnicamente perfeito, mas difícil de entender, tende a ser abandonado, usado de forma errada ou usado apenas por quem "decorou" o caminho certo. IHC existe porque a maior parte dos erros de uso não é culpa da pessoa que usa — é sintoma de uma interface que não considerou como as pessoas realmente pensam, enxergam e agem. Isso inclui limites de memória de curto prazo, tempo de reação, expectativas culturais e até cansaço.

Alguns conceitos centrais

  • Usabilidade — o quão fácil e eficiente é usar um sistema para atingir um objetivo específico.
  • Affordance — pistas visuais que sugerem como um elemento deve ser usado (um botão que "parece" clicável).
  • Feedback — a resposta do sistema a uma ação, confirmando que algo aconteceu.
  • Modelo mental — a ideia que a pessoa tem, na cabeça, de como o sistema funciona (nem sempre igual ao modelo real).
  • Carga cognitiva — o esforço mental exigido para operar a interface.

De IHC para UX/UI

UX (experiência do usuário) e UI (interface do usuário) são, hoje, os nomes que o mercado dá à aplicação prática dos princípios de IHC no design de produtos digitais. UX cuida da experiência como um todo — fluxo, arquitetura de informação, pesquisa com usuários. UI cuida da camada visual e dos componentes com os quais a pessoa realmente interage: botões, cores, tipografia, espaçamento.

É nesse ponto que entram as ferramentas de design de interface. O Figma é hoje uma das mais usadas para prototipar essas ideias antes de virarem código: permite desenhar telas, montar fluxos clicáveis e testar hipóteses de usabilidade com usuários reais, sem escrever uma linha sequer.
