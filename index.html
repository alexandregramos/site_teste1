Sobre este material

Este site foi construído como material de apoio para um trabalho sobre UX/UI e Interação Humano-Computador (IHC). A ideia é que cada aba funcione como um "frame" independente — como em uma ferramenta de design — cobrindo um recorte específico do tema, sempre com um link para uma fonte externa confiável para quem quiser ir além do resumo apresentado aqui.

UX/IHC LAB — material de estudo, não afiliado a NN/g, Figma ou W3C. 05 frames · HTML, CSS e JS
