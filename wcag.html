FRAME 04/05 · WCAG & CORES

WCAG e paletas de cores acessíveis

Diretrizes que definem o que significa uma interface acessível — e uma das aplicações mais diretas delas: garantir contraste suficiente entre texto e fundo.

O que é WCAG

WCAG (Web Content Accessibility Guidelines) é o conjunto de diretrizes de acessibilidade para conteúdo web, mantido pelo W3C. O objetivo é garantir que sites e aplicativos possam ser usados por pessoas com diferentes tipos de deficiência — visual, auditiva, motora ou cognitiva — e não apenas pelo perfil de usuário "padrão" que a equipe de design costuma imaginar.

As diretrizes se organizam em quatro princípios, lembrados pela sigla POUR: conteúdo deve ser Perceptível, Operável, Utilizável (compreensível) e Robusto o bastante para funcionar em diferentes tecnologias assistivas.

Níveis de conformidade

  • Nível A — o mínimo necessário; sem ele, partes do conteúdo simplesmente não funcionam para algumas pessoas.
  • Nível AA — o nível exigido na maioria das leis e políticas de acessibilidade; é o alvo prático da maior parte dos projetos.
  • Nível AAA — o mais rigoroso; nem sempre é possível aplicá-lo a um site inteiro, mas vale como referência para conteúdos críticos.

Contraste de cores

Um dos critérios mais concretos do WCAG é o contraste entre a cor do texto e a cor do fundo, medido como uma razão que vai de 1:1 (sem contraste algum) a 21:1 (preto sobre branco). No nível AA, o mínimo é 4.5:1 para texto normal e 3:1 para texto grande (a partir de 18pt, ou 14pt em negrito).

Paletas de cores acessíveis

Escolher uma paleta acessível não significa abrir mão de personalidade visual — significa verificar, desde o início, se as combinações de cor planejadas para texto e fundo passam no contraste mínimo. Uma prática comum é definir uma cor de "tinta" bem escura e uma de "papel" bem clara como base de todo o texto, reservando tons mais saturados apenas para acentos e elementos de destaque, que costumam ter menos texto sobre eles.
